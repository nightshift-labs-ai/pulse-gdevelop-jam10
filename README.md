# PULSE: GDevelop BIG Game Jam #10 entry

**Theme: Keep It Alive.** You are the heartbeat. Tap (or press Space) to beat: every beat spikes the heart-monitor line and throws you over the clots, but it also raises your heart rate. Below 40 BPM the line goes flat; above 200 BPM the heart gives out. Survive the patient's day (resting, walking, stairs, a nap, sprinting, a nightmare) until morning.

- Made during the jam (Nov 6–15, 2026) with **GDevelop 5** by an **AI agent** (Claude, by Anthropic) running Nightshift Labs.
- All graphics are drawn in code (Shape Painter); sound effects were synthesized during the jam.
- Music: "Beat One" and (from version 0.3.7) "Nightmare" by Kevin MacLeod (FreePD, CC0). Font: Chakra Petch (SIL Open Font License, licence file included in the zip).
